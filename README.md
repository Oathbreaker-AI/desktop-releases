# Oathbreaker Desktop releases

Official installers and checksums for Oathbreaker Desktop, published by Oathbreaker AI.

## Install

Get the current installer and setup instructions at [oathbreaker.ai/agents](https://oathbreaker.ai/agents#desktop).

The Mac build supports Apple Silicon (M1 or newer) on macOS 13 or later. Model inference uses your prepaid Oathbreaker API credit.

Each release includes SHA-256 checksums. Mac releases are signed with Developer ID and submitted to Apple for notarization before publication.

Oathbreaker Desktop builds on [Hermes Agent by Nous Research](https://github.com/NousResearch/hermes-agent), distributed under the MIT License. The application includes the upstream license and third-party notices.

Support: [support@oathbreaker.ai](mailto:support@oathbreaker.ai).

This repository holds release information and binary assets. The Oathbreaker application source is maintained separately.
